# Datenschutzerklärung – Recallo

*Stand: September 2026*

## Datenerhebung
Recallo erhebt, speichert oder überträgt keine personenbezogenen Daten.
Die App funktioniert vollständig offline und ohne Nutzerkonto, Login
oder Cloud-Anbindung.

## Datenspeicherung
Alle Inhalte (importierte Lerninhalte, Fortschritt, Statistiken) werden
ausschließlich lokal auf dem Gerät des Nutzers gespeichert. Es findet
keine Übertragung an Server Dritter oder des Entwicklers statt.

## Dateizugriff / Import
Recallo ermöglicht das lokale Importieren eigener Lerninhalte (Markdown-
Dateien) durch den Nutzer. Dieser Dateizugriff dient ausschließlich dem
Import der vom Nutzer selbst ausgewählten Inhalte und wird nicht zu
anderen Zwecken verwendet.

## Werbung
Recallo enthält keine Werbung.

## Berechtigungen
Recallo benötigt aktuell keine besonderen Geräteberechtigungen
(z. B. Kamera, Standort, Kontakte, SMS).

## Kontakt
Bei Fragen zu dieser Datenschutzerklärung:
recallo@gmx.de

# Privacy Policy – Recallo

*Last updated: September 2026*

## Data Collection
Recallo does not collect, store, or transmit any personal data.
The app works entirely offline, without any user account, login,
or cloud connection.

## Data Storage
All content (imported learning material, progress, statistics) is
stored exclusively on the user's local device. No data is transmitted
to any server operated by third parties or the developer.

## File Access / Import
Recallo allows users to import their own learning content (Markdown
files) locally. This file access is used solely to import content
selected by the user and is not used for any other purpose.

## Advertising
Recallo does not contain any advertising.

## Permissions
Recallo currently does not require any special device permissions
(e.g. camera, location, contacts, SMS).

## Contact
For questions regarding this privacy policy:
recallo@gmx.de
